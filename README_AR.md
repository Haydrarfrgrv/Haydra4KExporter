# Haydra 4K Exporter — نسخة أولية

يصدّر الفيديو بإطار 3840×2160 (4K) ويحاول الحفاظ على معدل الإطارات الأصلي.

## تنبيهات
- فيديو مصدره 60 FPS قد يبقى 60 FPS؛ التطبيق لا ينشئ إطارات جديدة.
- رفع 2K إلى 4K لا يضيف تفاصيل جديدة.
- نجاح التصدير يعتمد على دعم الهاتف لترميز 4K. هذه نسخة أولية ويجب اختبارها على الجهاز.
- لا تحتوي هذه النسخة على إعلانات.

## البناء من الهاتف عبر GitHub Actions
1. أنشئ مستودعًا عامًا جديدًا على GitHub باسم Haydra4KExporter.
2. فك ضغط ZIP على هاتفك.
3. ارفع محتويات المجلد إلى المستودع مع الحفاظ على مجلدات `app` و`.github`.
4. افتح تبويب Actions وانتظر انتهاء Build Haydra 4K Exporter APK.
5. افتح آخر تشغيل ونزّل Artifact باسم Haydra-4K-Exporter-APK.
6. فك ضغطه وثبّت `app-debug.apk`.

لا ترفع مفاتيح توقيع أو معلومات خاصة إلى المستودع.
